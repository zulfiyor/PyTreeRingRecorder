# PyTreeRingRecorder

Tree-ring measurement and crossdating for tree cores, stem disks and microscopic sections. Interface and help: **English · Русский · 中文**.

**[Download the latest release](https://github.com/zulfiyor/PyTreeRingRecorder/releases/latest)** · **[All releases](https://github.com/zulfiyor/PyTreeRingRecorder/releases)**

## English

PyTreeRingRecorder supports manual and automatic boundary placement, multiple radii and core images, paired points, missing rings, auxiliary ring markers and links, reference chronology comparison, Blue Intensity, and measurement import/export including POS, RWL, WID and CSV. Microscopic sections use a separate Cell-aware detector; core/disk and microsection training remain separate. Pencil drawings and shapes provide project annotations.

### Download and start

1. Open the latest release and download **PyTreeRingRecorder-Windows-x64.zip**. The current published package is for **Windows x64**.
2. Extract the complete ZIP to a writable folder. Keep all files and subfolders together.
3. Run **PyTreeRingRecorder/PyTreeRingRecorder.exe**. A separate installer, Python or Anaconda is not required for this packaged version.
4. Use the application's Help for measurement workflows and current controls. Activation is handled inside the application; the developer activator is not a user download.

Download the named application ZIP, **not** GitHub's automatically generated “Source code” archives. This repository distributes releases; those source archives are not the application.

### Guides and updates

PDF user guides are provided as release attachments in English, Russian and Chinese. The existing guide edition is **2026-10-18**; newer controls and fixes are described in the application Help and release notes. Read both when using the 2026-10-25 build.

The application checks official GitHub Releases for updates. The first update-enabled version must be downloaded manually once. Updates download the **complete application package**, validate its size/checksum, and replace the application folder after confirmation and closure. The previous version is retained for rollback. Settings, license and personal models in the user profile are preserved. A release must have a newer version/build to be offered as an update.

**PyTreeRingRecorder-update-windows-x64.json** is metadata for the updater; users do not need to open it. For developers: publish the matching ZIP and JSON together in a new Latest release. Google Drive may mirror the same unmodified files for manual downloads; the current automatic updater still checks GitHub.

## Русский

PyTreeRingRecorder — программа для измерения годичных колец и перекрёстной датировки кернов, дисков и микросекций. Поддерживаются ручная и автоматическая постановка границ, несколько радиусов и изображений, парные точки, пропущенные кольца, вспомогательные отметки и связи, сравнение с мастер-хронологией, Blue Intensity и обмен измерениями POS, RWL, WID и CSV. Для микросекций используется отдельный Cell-aware детектор; обучение микросекций и кернов/дисков разделено. Карандаш и фигуры служат аннотациями проекта.

### Скачать и запустить

1. Откройте [последний выпуск](https://github.com/zulfiyor/PyTreeRingRecorder/releases/latest) и скачайте **PyTreeRingRecorder-Windows-x64.zip**. Сейчас опубликована версия для **Windows x64**.
2. Полностью распакуйте ZIP в папку с разрешением записи. Все вложенные файлы и папки должны оставаться вместе.
3. Запустите **PyTreeRingRecorder/PyTreeRingRecorder.exe**. Устанавливать Python или Anaconda для готовой сборки не нужно.
4. Порядок измерений и актуальные инструменты описаны в Help. Активация выполняется в программе; активатор разработчика пользователям не нужен.

Не скачивайте автоматически создаваемые GitHub архивы **Source code** вместо ZIP программы.

### Руководства и обновления

PDF-руководства на русском, английском и китайском размещаются во вложениях релиза. Существующая редакция — **18 октября 2026 года**. Более новые функции и исправления описаны в Help программы и примечаниях к выпуску; для сборки от 25 октября используйте их вместе с руководством.

Первую версию с обновлятором нужно скачать вручную один раз. Далее программа проверяет GitHub и предлагает более новую версию/сборку. Скачивается **полный пакет программы**, проверяются размер и контрольная сумма; после подтверждения и закрытия программы её папка заменяется. Предыдущая версия сохраняется для отката. Настройки, лицензия и личные модели в профиле пользователя сохраняются.

Файл **PyTreeRingRecorder-update-windows-x64.json** предназначен для обновлятора — пользователю не нужно открывать его вручную. Для нового выпуска разработчик загружает соответствующие ZIP и JSON в новый релиз Latest. Те же неизменённые файлы можно зеркалировать в Google Drive для ручного скачивания; автообновление пока использует GitHub.
